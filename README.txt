1. PROJECT OVERVIEW
-------------------
Savanna Brew Café is a responsive multi-page website for a specialty Kenyan
coffee shop and roastery located in Westlands, Nairobi.

Included Pages:
- index.html   : Home page featuring hero showcase, highlights, favourites, story, and gallery preview.
- about.html   : Founder story (Amina Otieno), café heritage, and core values.
- menu.html    : Full menu with prices in KES across Hot Drinks, Cold Drinks, and Bakery & Snacks.
- gallery.html : Responsive CSS Grid photo gallery of crafted drinks, pastries, and café spaces.
- events.html  : Monthly community events and workshops in Westlands.
- contact.html : Table reservation form with interactive booking summary modal, opening hours, and embedded map.

Directory Structure:
- css/         : Modular stylesheets (global.css, index.css, aboutUs.css, menu.css, gallery.css, events.css, contact.css)
- images/      : Optimised image assets (logo.png, hero.jpg, about-owner.jpg, latte.jpg, cappuccino.jpg, croissant.jpg, gallery-1.jpg to gallery-8.jpg)
- README.txt   : Project documentation and W3C validation statement.
